# Lab 5 · Movie Seats · Course starter 09

This revision of the [course starter](https://github.com/SETAPESU26/L5_09_movie_seats/tree/4fc0f2be2e52b76844cf79d855071f2e8761acb1) reserves and releases seats, generates a ticket reference and persists the seating plan. Use a new folder or an existing valid seats.json when running the CLI.

```sh
python theater_system.py
python -m unittest -v
python -m pip install pylint flake8 bandit
python -m pylint theater_system.py
python -m flake8 theater_system.py
python -m bandit theater_system.py
```

The [issue register](issues.md) uses the original starter line numbers. The [reflection](reflection.md) explains the domain bugs. The [reports](reports/) contain before and after output from all three tools.
